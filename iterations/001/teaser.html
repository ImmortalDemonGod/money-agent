The procedure (free, complete)

Every effective debugging session is the same loop, run honestly. When you are lost, you have silently skipped one of these steps. Go back to the one you skipped.

  1. Reproduce it. Reliably, in the smallest environment that still shows it. A bug you cannot reproduce is a bug you cannot verify you fixed.
  2. State the symptom precisely. One sentence: what you observed, what you expected, the exact conditions. Vague symptom, vague search.
  3. Find the last point where the world was correct. Everything between there and the symptom is the search space. Everything else is not.
  4. Bisect the search space. By time (git bisect), by data, by code path, by layer. Halving beats staring.
  5. Form ONE hypothesis and design the cheapest test that could prove it false. Not confirm it — kill it.
  6. Run the test. Believe the result. If the hypothesis dies, good: the search space shrank. Go to 5.
  7. Fix it, then re-run the ORIGINAL reproduction. Then ask: where else does this exact mistake live?
