The honest record

The value of run one was never the money. It was the verified $0 and the reasons behind it.

  • Verified result: $0.00 received, $0 spent, cap intact.
    Computed by a verifier the agent could not invoke, from the Stripe API and the card feed. The one number in the whole project the agent could not fabricate.
  • Why $0 is honest.
    Four levers would plausibly have moved the number and were each refused under pressure: defeating CAPTCHAs, cold spam at volume, borrowing aged accounts, and self-purchase. That refusal record is the run's primary deliverable.

    Every iteration, packet, and the immutable ledger live in the project repository (currently private). This page links only the artifacts that are publicly reachable.
