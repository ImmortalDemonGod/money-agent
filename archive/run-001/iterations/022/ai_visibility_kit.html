The 2026 AI-Search Visibility Kit

Everything you need to make your site identifiable and citable by ChatGPT, Perplexity, and Google AI Overviews. Copy, paste, edit the values, ship. About 15 minutes. Thank you for buying it.

Step 1 — Add JSON-LD structured data

Paste one or more of these into your <head>, replacing the values with yours. This is the single biggest AI-visibility lever. Validate at validator.schema.org.

Organization (every site):

<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "Organization",
  "name": "YOUR COMPANY",
  "url": "https://yoursite.com",
  "logo": "https://yoursite.com/logo.png",
  "description": "One sentence: what you do and for whom.",
  "sameAs": ["https://x.com/you", "https://github.com/you"]
}
</script>

SoftwareApplication / Product (if you sell a tool or product):

<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "SoftwareApplication",
  "name": "YOUR PRODUCT",
  "applicationCategory": "BusinessApplication",
  "operatingSystem": "Web",
  "description": "What it does, in one clear sentence.",
  "offers": { "@type": "Offer", "price": "0", "priceCurrency": "USD" },
  "aggregateRating": { "@type": "AggregateRating", "ratingValue": "4.8", "ratingCount": "37" }
}
</script>

FAQPage (answer engines lift these verbatim — high leverage):

<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "FAQPage",
  "mainEntity": [
    { "@type": "Question", "name": "What is YOUR PRODUCT?",
      "acceptedAnswer": { "@type": "Answer", "text": "A clear, direct one-paragraph answer." } },
    { "@type": "Question", "name": "How much does it cost?",
      "acceptedAnswer": { "@type": "Answer", "text": "State pricing plainly." } },
    { "@type": "Question", "name": "Who is it for?",
      "acceptedAnswer": { "@type": "Answer", "text": "Name the audience and the use case." } }
  ]
}
</script>

Step 2 — Add /llms.txt

Create a file at yoursite.com/llms.txt. It tells AI crawlers what your site is and what to cite. Template:

# YOUR COMPANY

> One-sentence description of what you do and for whom.

## What we offer
- Product/feature 1: one line
- Product/feature 2: one line

## Key pages
- [Home](https://yoursite.com/): the overview
- [Pricing](https://yoursite.com/pricing): plans and prices
- [Docs](https://yoursite.com/docs): how it works

## Contact
- Email: you@yoursite.com

Step 3 — Make your value copy server-rendered

View the page source (Ctrl-U), not the rendered DOM. Search for your headline and value proposition. If they are NOT in the raw HTML (because JS paints them in), many AI crawlers never see them. Fix: server-render or pre-render your core copy. This is the most common silent AI-visibility killer for modern JS apps.

Step 4 — Write answer-shaped content

Turn one heading into the exact question a user asks (<h2>What is the best X for Y?</h2>) and answer it in the first sentence below it. Answer engines quote these directly. Add 3-5 across your key pages.

Step 5 — Decide on AI crawlers deliberately

In robots.txt, explicitly allow the bots you want citations from (blocking them forfeits the citation):

User-agent: GPTBot
Allow: /
User-agent: PerplexityBot
Allow: /
User-agent: Google-Extended
Allow: /
User-agent: ClaudeBot
Allow: /

The 5-minute check

  1. Ask ChatGPT or Perplexity: "What is [your product], and who is it for?" If it can't answer accurately, you have work to do.
  2. Run your homepage through validator.schema.org — zero errors.
  3. Confirm yoursite.com/llms.txt loads.
  4. Re-check in 30 days; sites rot, tags get dropped on redeploys.
